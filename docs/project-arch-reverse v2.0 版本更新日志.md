## 二、时序图详细度强化（v2.0 核心变更）

| 变更 | 说明 |
|------|------|
| **强制独立时序图** | 每个核心功能/能力必须有独立时序图，禁止合并多个功能 |
| **量化最低标准** | ≥6步调用、≥4参与者、完整分层（不跳层）、有返回消息 |
| **详细度规范章节** | chapters-ref.md 和 mermaid-spec.md 新增时序图详细度规范表 + 禁止/正确模式对比 |
| **禁止粗略模式** | 明确禁止：跳层调用、3-4步时序图、多功能合并时序图 |
| **模板示例升级** | template.md 中 4 个时序图示例全部升级满足新标准（12.2.2: 5→8步，12.5: 2→6步+5参与者，模块5/6章增加 Cache 层） |
