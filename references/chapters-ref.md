## 流程图代码标注规范 ★

> 所有流程图和时序图的每个步骤必须标注方法名和代码位置，并附带**步骤API详解表**和**关键代码示例**。

### 流程图节点格式
```
节点ID["步骤名称<br/>⚙️ ClassName.method()<br/>📁 文件路径:行号"]
```

### 时序图消息格式
```
箭头消息: 方法名(参数)
Note right of 参与者: 📁 文件路径:行号
```

### 步骤API详解表格式（必需）★
```
| 步骤 | 调用者/组件 | 被调用者 | 方法签名 | 参数 | 返回 | 代码位置 | 说明 |
|------|------------|----------|----------|------|------|----------|------|
```

### 关键类表格格式
```
| 类名 | 文件路径 | 行范围 | 关键方法 | 功能说明 |
```
每个关键方法的子章节应包含：**功能、完整签名、参数、返回、前置条件、副作用、异常处理、调用链、代码示例**。

### 核心方法详情格式（属性面板）★
```
##### `ClassName.method()` — 📁 文件路径:行号

| 属性 | 说明 |
|------|------|
| **功能** | 一段话描述 |
| **完整签名** | `返回类型 方法名(参数类型 参数名)` |
| **参数** | `参数名`: 类型 — 含义 |
| **返回** | `返回类型` — 含义 |
| **调用链** | `调用者A.方法()` → `本方法()` → `被调用B.方法()` |
| **代码示例** | 见下方代码块 |
```
